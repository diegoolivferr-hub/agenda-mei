# Agenda-MEI 

Aplicação front-end para gestão de agendamentos e serviços voltada a Microempreendedores Individuais (MEI). Interface desenvolvida a partir de protótipo Figma.

## 🛠️ Tecnologias Utilizadas
- **Core:** React + TypeScript
- **Build & Dev Tool:** Vite
- **Estilização:** Tailwind CSS
- **Design System:** Prototipado no Figma
- **Versionamento & Deploy:** Git, GitHub / Vercel
